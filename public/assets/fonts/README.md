These Latin WOFF2 subsets are hosted with the application so rendering does not
depend on Google Fonts, an external stylesheet, or additional TLS connections.
They are unmodified Google Fonts distributions under the included SIL Open Font
Licenses. `font-display: swap` keeps text readable while fonts load.
